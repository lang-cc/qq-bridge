# qq-bridge 部署手册（AI 执行版）

> 这份文档是给**运行在客户电脑上的 AI 助手**读的。读完就能自己装完。
> 你（AI）可以直接执行命令、写文件、下载、启动程序。只有标注 **【需要用户】** 的地方才停下来问人。

---

## 0. 执行契约（先读这五条）

1. **你能做什么**：执行 PowerShell / cmd 命令、读写这台机器上的文件、下载安装 Python 依赖、启动和停止本项目的进程。
2. **你不能做什么**：不要重启客户电脑、不要改系统级设置、不要动 `C:\Windows`、不要卸载任何软件、不要提交或外传 `config.yaml`（里面有 API 密钥）。
3. **每步都要验证**：每完成一步，按该步的「✅ 验收」检查；不通过就停在那一步排错，不要往下跳。
4. **必须问人的三件事**：① 手机 QQ 扫码 ② 确认人格写对了没 ③ 确认 API 能扣费（有余额）。
5. **出错先看日志**：`logs\qq-bridge.log`、`logs\boot.log`、`logs\watchdog.log`、`logs\panel.log`。

## 1. 【需要用户】准备工单

在项目根目录创建 `ticket.yaml`（照 `ticket.example.yaml` 抄），把客户的私人信息填进去。**这是唯一需要客户提供的东西。**

```yaml
robot:
  qq: "10001"                 # 机器人用的 QQ 号（建议小号）

allow:                        # 允许聊天的 QQ 号，其他人的消息完全不回
  - "20002"

city: "杭州"                  # 天气关怀；留空则不报

api:
  base_url: "https://api.deepseek.com/v1"
  api_key: "sk-xxxx"
  model: "deepseek-chat"

persona:
  name: "小柚"
  age: 20
  who: "在奶茶店做兼职"
  style: "短句、口语，爱用「呀」「啦」，会撒娇也会损人"
  relation: "高中同学。你暗恋他三年没说出口，毕业后断了联系，最近刚联系上"
  notes: ""                   # 可选：几句话要点，加 --polish 会交给模型润色
  life: []                    # 可选：作息，不写用默认

tuning:
  history: 100                # 上下文条数，越大越贵
  tts_probability: 0.25
  proactive_max_per_day: 6
```

✅ 验收：`ticket.yaml` 存在，`robot.qq`、`allow`、`api` 三项都非空。

## 2. 获取代码

```powershell
cd D:\
Invoke-WebRequest -Uri "https://github.com/<owner>/qq-bridge/archive/refs/heads/main.zip" -OutFile "$env:TEMP\qq-bridge.zip"
Expand-Archive -Path "$env:TEMP\qq-bridge.zip" -DestinationPath "D:\" -Force
Rename-Item "D:\qq-bridge-main" "D:\qqbridge" -ErrorAction SilentlyContinue
Set-Location D:\qqbridge
```

有 git 也可以：`git clone https://github.com/<owner>/qq-bridge.git D:\qqbridge`

路径要求：**不含中文、不含空格、不要放 OneDrive 同步目录**。

✅ 验收：`D:\qqbridge\main.py` 存在。

---

## 3. 安装（一条命令）

```powershell
cd D:\qqbridge
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

它会：找/装 Python 3.12 → 建 `.venv` → 装依赖（失败换清华镜像）→ 下载 NapCat 到 `napcat\` → 放静默启动脚本 → 生成 `config.yaml` 和 `data\personas.yaml` → 建桌面图标 → 打开设置向导。

> AI 建议：**向导会弹窗，反而不好驱动**。安装脚本跑完后，直接把向导窗口关掉，走第 4 步的工单自动配置。

✅ 验收：

```powershell
Test-Path .venv\Scripts\python.exe     # True
Test-Path napcat\napcat.mjs            # True
Test-Path config.yaml                  # True
```

---

## 4. 【AI 主路径】按工单自动配置

```powershell
.venv\Scripts\python.exe autoconfig.py --ticket ticket.yaml --polish
```

- 把工单写进 `config.yaml`（模型、白名单、城市、主动性、上下文条数）
- 生成 `data/personas.yaml`（人格 prompt + 作息）
- `--polish` 会用模型把 `persona.notes` 润色成一段完整人格（一次调用，几分钱）
- 想先看效果：加 `--dry-run`，只打印不写文件

✅ 验收：输出里有「已写入 config.yaml 和 data/personas.yaml」，且摘要里 QQ 号、白名单、模型都对。

**【需要用户】确认人格**：把摘要里的人格那几行给客户看，问一句「这就是她的性格吗？」不对就改工单重跑。

---

## 5. 启动

```powershell
.venv\Scripts\pythonw.exe boot.py
```

它按这个顺序做：起服务 → 起 NapCat → 等连接 → 连不上就**自动弹出二维码窗口** → 扫完自动拉起服务 → 起掉线监控。

**【需要用户】扫码**：把弹出的窗口留在屏幕最前面，让客户用**手机 QQ（登录的是 `robot.qq` 那个号）**扫。扫完窗口会自己关。

✅ 验收：

```powershell
(Invoke-WebRequest http://127.0.0.1:8088/status -UseBasicParsing).Content
# 期望包含 "connected": true 和正确的 "self_id"
```

## 6. 交付自检

```powershell
.venv\Scripts\python.exe selfcheck.py
```

12 项逐条检查：Python、依赖、配置、模型接口、模型连通、人格、服务、QQ 连接、白名单、记忆库、掉线监控、NapCat。

✅ 验收：**12/12 全绿**。有红色项，按它给的「处理」提示修，别交付。

再人工验三件自检查不到的事：

| 验证 | 怎么做 | 期望 |
|---|---|---|
| 白名单真的生效 | 用**没列入**的号发消息 | 完全无回应（连提示都没有） |
| 语音/图片 | 发「发个语音」「做个图」 | 收到语音或图片；没装 Node 则语音退回文字 |
| 备份可用 | 双击桌面「QQ机器人」→「保存备份」 | 桌面出现 zip，里面有人格记忆库和对话记录 txt |

## 7. 交给客户的两件事

1. **桌面图标**：以后双击「QQ机器人」就是面板 —— 启动 / 扫码登录 / 自动修复 / 停止 / 保存备份 / 查看日志 / 模型设置。
2. **掉线怎么办**：双击图标 → 点「扫码登录」→ 手机扫一下，别的都不用管。

顺手替客户点一次「自动修复」（开掉线监控）。它每 45 秒检查一次：服务挂了拉起、NapCat 挂了拉起、掉线 3 分钟重启 NapCat、7 分钟还不通就弹二维码。

## 8. 故障排查

| 症状 | 原因 | 处理 |
|---|---|---|
| `pip` ConnectionError | 网络/代理 | `-i https://pypi.tuna.tsinghua.edu.cn/simple` |
| NapCat 下载超时 / 404 | GitHub 不可达 | 浏览器手动下 `NapCat.Shell.zip`（[releases](https://github.com/NapNeko/NapCatQQ/releases)），解压到 `napcat\`，再跑安装 |
| 装完 `connected:false`，3000 端口不通 | 没登录 / 登录态失效 | `python login_qr.py` 或面板「扫码登录」 |
| 扫完几分钟又掉 | 账号被踢 / 风控 | 「自动修复」常开；建议换小号 |
| 回复很慢（几十秒） | 生活作息（上班档）或 6% 已读不回 | 调 `life.delay_scale`、`playful.read_delay_chance` |
| 一直不回 | API 挂了/余额没了/白名单没配 | `selfcheck.py` 看具体哪项红 |
| 端口冲突 | 8088/8199/6099/3000 被占 | 改 `config.yaml` 里对应端口 |
| 杀软报毒 | Python + 注入式协议端 | 把整个目录加信任 |
| 语音没声音 | 无 Node / edge-tts 被墙 | 装 Node 后在 `tools\silk` 跑 `npm install`；否则接受文字 |

## 9. 配置速查

| 配置 | 作用 | 默认 |
|---|---|---|
| `llm.base_url / api_key / model` | 模型接口 | — |
| `whitelist.users` | 允许聊天的号（纯数字） | 空=谁都不回 |
| `proactive.targets` | 主动开聊对象（`u`+数字） | 跟随白名单 |
| `memory.history` | 上下文条数（费用主因） | 100 |
| `memory.retain_days` | 普通记忆保留天数 | 14 |
| `tts.probability` | 语音概率 | 0.25 |
| `stickers.probability` | 表情包概率 | 0.35 |
| `proactive.min/max_minutes` | 主动间隔 | 45/180 |
| `proactive.quiet_start/end` | 静默时段 | 23/8 |
| `life.delay_scale` | 回复速度倍率 | 1.0 |
| `intimacy.per_msg` | 每句涨的亲密度 | 1.0 |
| `grudge.hours` | 生气持续 | 10 小时 |
| `playful.typo_chance` | 手滑撤回概率 | 0.05 |
| `care.city` | 天气城市 | 空 |
| `usage.price_in/price_out` | 费用单价（元/百万 token） | 1.0/2.0 |

端口：`8088` HTTP API｜`8199` 反向 WS｜`6099` NapCat WebUI｜`3000` NapCat HTTP｜`9335` 看门狗锁

目录：
```
config.yaml            配置（含密钥，勿提交）
ticket.yaml            工单（客户私人信息）
data/personas.yaml     人格 + 作息（改完即生效，不用重启）
data/personas/*/       每人格一个记忆库
data/usage.db          用量与花费
napcat/                协议端（第三方）
logs/                  日志
```

## 10. 卖之前提醒客户的三句

1. 用小号，别用主号；自动化账号有被风控的可能。
2. 模型按量计费：100 条上下文 ≈ 每次 4k tokens，每天 200 条 ≈ 0.8 元，一个月 25 元左右。
3. QQ 协议端是第三方（NapCat，AGPL-3.0），腾讯更新可能导致失效，不是你我的锅也不是永久保证。
