# 远程代装 · 操作手一页纸（给自己看）

目标：人不用去现场，把包和任务单发给客户机上的 AI（或自己远程连上去），
10–20 分钟装完，只剩客户手机扫码这一步。

---

## 一、你只需要做三件事

1. **填单子**：把 `docs/任务单-AI部署.md` 的【① 填写区】填好（QQ 号、白名单、模型三项、性格、城市、选 A 还是 B）。
2. **给包**：把 `dist\qq-bridge-full-20261027.zip`（Windows）或 `dist\qq-bridge-code-*.zip`（Linux，走 URL）给对方。
3. **发过去 + 一句话**：

> 按这份任务单执行。需要人工的只有扫码、确认人格、放行安全组，其他你自己做完。

---

## 二、两种部署分别怎么走

| | A. Windows 本地 | B. Linux 服务器（阿里云） |
|---|---|---|
| 谁在跑 | 客户的电脑，QQ 也登录在那台机器 | 云服务器，24 小时在线 |
| 你怎么连 | ToDesk / 向日葵 / RDP，把包传上去 | SSH：`ssh root@<IP>` |
| 装多久 | 5–10 分钟（含 pip） | 10–15 分钟（含 Docker 拉镜像） |
| 你给的命令 | `powershell -File deploy.ps1 -ZipPath D:\qq-bridge-full.zip -TicketPath D:\ticket.yaml` | 任务单 ④ B2 那条 `QQ=... bash <(curl ...)` |
| 关机就下线？ | 是 | 否 |
| 需要人做的 | 手机扫码 | 安全组放行 6099 + 手机扫码 |

细节步骤、判据、报错处理全在 `docs/任务单-AI部署.md` 里，AI 照着做就行。

## 三、发之前要把包传到 Gitee（只做一次，之后不用管）

`docs/任务单-AI部署.md` 里写死了两个下载地址，你的仓库得真有这两个文件：

| 文件 | 传到哪 | 用途 |
|---|---|---|
| `qq-bridge-code.zip`（0.3MB） | `gitee.com/wangcc111/qq-bridge-dist` **仓库根目录**（raw 直链） | Linux 部署脚本自动下载代码 |
| `qq-bridge-full.zip`（59MB） | 同仓库 **发行版 v2.0** 附件 | Windows 客户机整包 |

生成方式（本地跑）：

```powershell
.venv\Scripts\python.exe tools\make_dist.py --all --with-assets --with-napcat
```

产物在 `dist\`：

- `qq-bridge-code-<日期>.zip` + 固定名副本 `qq-bridge-code.zip`
- `qq-bridge-full-<日期>.zip` + 固定名副本 `qq-bridge-full.zip`

> 上传后自测一下这两条能不能匿名下：
> `curl -sI https://gitee.com/wangcc111/qq-bridge-dist/raw/main/qq-bridge-code.zip`
> `curl -sI https://gitee.com/wangcc111/qq-bridge-dist/releases/download/v2.0/qq-bridge-full.zip`
> 如果换了发行版标签（v2.0 → v2.1），记得同步改任务单 A1 里的 URL。

## 四、你远程连上去时，最省事的顺序（Windows）

```powershell
# 1) 把包放到目标机 D:\，解压成安装目录
Expand-Archive -Path D:\qq-bridge-full.zip -DestinationPath D:\qqbridge -Force

# 2) 一条命令装完（含配置，工单是自己写好的 ticket.yaml）
cd D:\qqbridge
powershell -NoProfile -ExecutionPolicy Bypass -File .\deploy.ps1 -InstallDir D:\qqbridge -TicketPath D:\ticket.yaml

# 3) 看状态
curl.exe http://127.0.0.1:8088/status

# 4) 扫码（如果 connected=false）
Start-Process D:\qqbridge\.venv\Scripts\python.exe -ArgumentList login_qr.py -WorkingDirectory D:\qqbridge

# 5) 验收
.venv\Scripts\python.exe selfcheck.py
```

`ticket.yaml` 就是你填的 ① 转成的 YAML（模板在任务单 A2）。

## 五、红线

- **密钥只写在客户机本地**，不要贴到群里、不要写进聊天记录、不要放进截图。
- 交付完提醒客户：改掉远程工具密码；云服务器把安全组 6099 收回。
- 打包只用 `tools\make_dist.py`（它已经排除 `config.yaml` / `nb.env` / `data/` / `logs/` / `.venv` / `napcat/`）。
- 客户**关机就下线**这件事必须提前讲清楚；要 24 小时在线就上 Linux（方案 B）。
