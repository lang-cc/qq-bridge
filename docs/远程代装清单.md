# 远程代装 · 操作清单（20 分钟一单）

给装机的人看的。照着念、照着点，不用临场想。

---

## 一、开场前先拿到这 4 样（缺一个就别开始）

| # | 要的东西 | 为什么 | 用什么问客户 |
|---|---|---|---|
| 1 | **机器人用的 QQ 号** | 要登录这个号 | 「有没有不常用的小号？最好别用你主号」 |
| 2 | **手机 QQ**（能扫这个号） | 扫码登录只能本人做 | 「等会手机上 QQ 扫一下码」 |
| 3 | **模型 API**：地址 + 密钥 + 模型名 | 没有它不能说话 | 「你在哪买的 API？后台复制 base_url 和 key 给我」 |
| 4 | **人格设定**（下面问卷） | 决定像不像人，最花时间 | 「先回答我 6 个问题」 |

### 人格问卷（复制给客户，一次问完）

```
1. 她叫什么？大概几岁？
2. 她是做什么的？（学生 / 上班 / 开店 / 待在家…）
3. 她怎么说话？（话多话少、爱用什么语气词、会不会撒娇/损人）
4. 你和她什么关系？（朋友 / 暧昧 / 前任 / 暗恋 / 已在一起）
5. 有没有什么「没说破」的事？（例如：她暗恋你但装没事）
6. 她平时几点睡、几点忙？（默认：1-8 睡，8-17 忙，17-22 闲，22-1 熬夜）
```

客户答得敷衍也没关系——把答案直接丢给任意 AI：「按这 6 条写一段 200 字的中文人格 prompt，第二人称『你是…』」，粘进向导即可。

## 二、时间表（照着走，20 分钟）

| 时间 | 做什么 | 说什么 |
|---|---|---|
| T+0 | 开屏幕共享，看系统版本和 QQ 版本 | 「先看下你电脑，Win10/11 都行；QQ 得是最新版」 |
| T+2 | 让客户开浏览器下载仓库 ZIP | 「打开 github.com/你的用户名/qq-bridge，绿色 Code → Download ZIP」 |
| T+3 | 解压到 `D:\qqbridge`（**路径别带中文和空格**） | 「解压到 D 盘根目录，路径别有中文」 |
| T+5 | 双击 `安装.bat`，等 2-3 分钟 | 「它在装 Python 环境和 QQ 协议端，会有黑窗口，别关」 |
| T+8 | 向导第 1 页：QQ 号、白名单、城市 | 「填机器人的号，还有允许它聊天的号——只有这些号它会回」 |
| T+9 | 第 2 页：API 三项，点「测试连接」 | 「看到绿字『连通』才能下一步，红字就是地址或密钥不对」 |
| T+12 | 第 3 页：人格五项，点「预览她的人设」 | 「这是她的性格，之后随时能改」 |
| T+15 | 第 4 页「完成并启动」→ 弹二维码 → 客户扫码 | 「手机 QQ 扫这个码，扫完窗口会自己关」 |
| T+17 | 跑自检：`.venv\Scripts\python.exe selfcheck.py` | 「12 项全绿就装好了」 |
| T+18 | 客户在 QQ 里发一句「在吗」，看回复 | 「你发一句试试，她一般 3-10 秒回」 |
| T+20 | 面板「保存备份」，教客户双击桌面图标 | 「以后双击这个图标，就能启动/扫码/备份」 |

**必须留的两个保险**：面板里点一次「自动修复」（开掉线监控）；确认白名单里只有客户的号。

```bash
cd D:\qqbridge

```

| 项 | 要求 |
|---|---|
| Python 版本 / 依赖 | ✅ |
| 配置文件 | ✅ |
| 模型接口 / 模型连通 | ✅ 且测试通过 |
| 人格 | ✅ 有 prompt |
| 服务运行 / QQ 已连接 | ✅ 显示客户 QQ 号 |
| 白名单 | ✅ 只有客户指定的号 |

3. 面板「保存备份」→ 桌面出现 zip，能打开

## 四、常见意外与处理

| 症状 | 原因 | 处理 |
|---|---|---|
| 装 Python 那步失败 | 没网 / 系统太旧 | 手动装 python.org 的 3.12，勾 Add to PATH，重跑 `安装.bat` |
| pip 装不动 | 网络被墙/公司代理 | 脚本会自动换清华镜像；还不行就手机热点 |
| NapCat 下载 404/超时 | GitHub 被拦 | 用浏览器手动下 `NapCat.Shell.zip`，解压到 `napcat\`，再跑一次安装 |
| 二维码扫了没反应 | QQ 版本不匹配 | 把 QQ 更新到最新版，重启「QQ机器人」 |
| 扫完几分钟又掉 | QQ 在别处登录 / 风控 | 面板「自动修复」常开，看门狗会自动重登 |
| 回复报错 / 一直不说话 | API 挂了或余额没了 | 面板「模型设置」→ 测试连接 → 看红字提示 |
| 杀软报毒 | Python 脚本 + 协议端注入 | 加信任目录；提前跟客户说明 |
| 端口 8088 被占 | 客户机器上有别的服务 | 改 `config.yaml` 的 `http_api.port` |

## 五、交付给客户的两句话（连同桌面图标一起说）

1. **「掉线了别慌」**：双击桌面「QQ机器人」→ 点「扫码登录」→ 手机扫一下就好了，其他什么都别动。
2. **「想换性格或换模型」**：还是那个面板，点「模型设置」或直接跟我说，我远程给你改。

## 六、报价参考（自己心里有数）

- 装机服务：按上面流程 20-30 分钟一单，含人格撰写
- 模型费用：100 条上下文 ≈ 每次 4k tokens；正常聊天 200 条/天 ≈ **0.8 元/天**，一个月 25 元左右
- 卖之前务必**给每单设日限额**，否则客户换成贵模型会烧钱
