# 语音音色怎么配（给客户的说明）

机器人本身带语音能力（自动把文字转成 QQ 语音发出来），但**音色要绑定在你自己的阿里云账号上**，
所以装好之后还需要做一步：用参考音频复刻一个音色。

## 一、准备（阿里云百炼）

1. 打开 <https://bailian.console.aliyun.com> ，登录 / 注册并完成实名认证
2. 左侧「API-KEY 管理」→ 创建 API Key，拿到 `sk-` 开头的一串
3. 确认语音合成模型 `cosyvoice-v3.5-plus` 已开通（模型广场里找一下，没开通点开通）

## 二、复刻音色

参考音频已经放在 `data/voice/xiaoling-ref.wav`（24 秒干净人声）。在本目录下执行：

```bash
python tools/clone_voice.py --audio data/voice/xiaoling-ref.wav --key sk-你自己的key
```

成功后会打印一行 `voice_id = cosyvoice-v3.5-plus-xxxx-...`，把它连同 key 填进 `config.yaml`：

```yaml
autoreply:
  tts:
    enabled: true
    provider: aliyun
    model: cosyvoice-v3.5-plus
    voice: cosyvoice-v3.5-plus-xxxx...     # 上面打印的 voice_id
    api_key: sk-你自己的key
```

也可以一步写完，省得手抄：

```bash
python tools/clone_voice.py --audio data/voice/xiaoling-ref.wav --key sk-你自己的key --write-config config.yaml
```

然后重启服务（Windows 双击 `重启.bat`，Linux `systemctl restart qqbot`）。

## 三、说明

- 音色按账号走：同一个参考音频，在不同账号下复刻会得到不同的 `voice_id`，互不通用
- 复刻按次计费，合成按字符计费，具体看百炼的定价页
- 参考音频要求：单声道人声、10~60 秒、无背景音乐、没有第二个人说话
- 想换成别的声音，换一段参考音频再跑一次上面的命令就行
- 复刻他人声音需要授权，请只用于自己的账号、别对外冒充
